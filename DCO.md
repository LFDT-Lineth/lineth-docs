Developer Certificate of Origin
===============================

Every commit submitted to this repository needs a
[Developer Certificate of Origin](http://developercertificate.org/) (DCO)
sign-off.
The LFDT-Lineth organization ruleset runs the DCO check.
A commit without a sign-off fails that check.

The sign-off needs to use your legal name, not a pseudonym.
Git adds it with the `-s` or `--signoff` argument to `git commit`, using your
`user.name` and `user.email`.

```bash
git commit -s -m "<COMMIT-MESSAGE>"
```

The commit message then ends with a line like this:

```text
Signed-off-by: Legal Name <email@address>
```

If you have any questions, you can reach us on the
[Lineth Discord](https://discord.gg/hyperledger).
